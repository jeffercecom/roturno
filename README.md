# Asesores — starter

Proyecto inicial para gestionar alta diaria de asesores, aprobación, asignación a oficinas y vista pública de disponibilidad.

Quick start:

```bash
# from project root
npm install
copy .env.example .env   # PowerShell: Copy-Item .env.example .env
npx prisma generate
npx prisma migrate dev --name init
npm run dev
```

Usa Git Bash if PowerShell bloquea scripts.
